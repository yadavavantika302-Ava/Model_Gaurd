Inspect and test a trained model

Upload an existing supported model and tabular CSV rows to inspect saved configuration, actual predictions, and available explanations.

Safe formats: .onnx (one tabular input/output), .tflite (one input/output), and .keras (safe-mode loading). Arbitrary pickle/joblib, .h5, and TorchScript uploads are blocked because they may execute code.
Only artifacts generated by this app are listed; uploaded joblib files remain blocked.
Use the expected input columns. Include true labels if you want evaluation metrics.
